SUPER OPTIMIZER V3.6.0 SMART CARE RC7
=====================================

Esta build é uma candidata avançada, mas ainda requer o AUTO-TESTE no Windows real antes de remover RC.

Fluxo recomendado:
1. preserve/copie a pasta State da versão anterior
2. abra o programa
3. execute Diagnóstico > AUTO-TESTE até RESULTADO
4. teste Analisar limpeza
5. teste Buscar atualizações (WinGet)
6. se usar DNS Jumper, coloque DnsJumper.exe em SuperOptimizer\Tools
7. só depois teste Limpeza Final e Otimizar Windows
