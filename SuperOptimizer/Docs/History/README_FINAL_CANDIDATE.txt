SUPER OPTIMIZER V3.3 FINAL CANDIDATE
=====================================

ANTES DE ATUALIZAR
Se você já usou uma versão anterior no mesmo PC, preserve a pasta:
    SuperOptimizer\State
Ela contém os backups necessários para rollback.

TESTE RECOMENDADO
1. Abra o SuperOptimizer.bat.
2. Confira o Dashboard.
3. Execute Diagnóstico -> AUTO-TESTE.
4. Teste uma ação leve: Limpar DNS.
5. Teste Manutenção Semanal.
6. Se usar EmptyStandbyList.exe, coloque-o em SuperOptimizer\Tools.
7. Só depois teste perfis ou ações avançadas.
