SUPER OPTIMIZER V3.4.1 FINAL AUDITED RC
========================================

1. Extraia o ZIP inteiro.
2. Se você já usou uma versão anterior, preserve/copiei sua pasta SuperOptimizer\State para esta versão antes de reaplicar perfis ou usar Rollback.
3. Abra SuperOptimizer.bat.
4. Execute Diagnóstico > AUTO-TESTE.
5. Confirme que todos os testes passam.
6. Use Dashboard / Manutenção / Gaming normalmente.

A pasta State contém os backups necessários para rollback e é separada por MachineGuid.
Não apague State depois de aplicar otimizações se quiser manter a restauração original.

EmptyStandbyList.exe não é distribuído. Se quiser as ferramentas manuais de RAM, coloque seu executável em SuperOptimizer\Tools\EmptyStandbyList.exe.
